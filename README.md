# AI Career & Skill-Gap Analyzer

## About the Project
AI Career & Skill-Gap Analyzer is a Python-based web application developed using Streamlit. It helps users analyze their skills, identify skill gaps, compare career options, and explore learning roadmaps.

## Features
- User career profile
- Resume PDF skill extraction
- Career skill-gap analysis
- Career comparison
- Learning roadmap and progress tracker
- Dataset-based job recommendations
- Career report download
- Dataset preview and analysis

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TF-IDF and Cosine Similarity

## Dataset
Dataset: Indian Tech Career Intelligence 2026

Source: [Hugging Face Dataset](https://huggingface.co/datasets/Uzaib52/indian-tech-career-intelligence-2026)

Dataset authors: Uzaib Saiyad, Pushkar Sharma, and Rajesh Sable.

The dataset page declares the MIT License. Please refer to the original dataset page for its licence and details.

## How to Run
1. Install Python.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python -m streamlit run app.py`

## Important Note
The career match score is based on the application's own skill-overlap and text-similarity calculations. It is not a guarantee of employment or an official company hiring prediction.

This project is developed for educational purposes.
